# CV Generator 📝

A simple and interactive CV Generator built with **React** and **Gemini API** (Google Generative Language API). This app takes your input and organizes your educational and practical experience into professional resume-ready text.

## ✨ Features

- Live input fields for name, email, and phone number
- Real-time email validation (`@gmail.com` only)
- Dynamic text area with AI-generated formatting for:
  - 📚 Educational experience
  - 💼 Practical/Job experience
- Displays formatted CV on submission
- Responsive and modern UI using custom CSS
- Gemini 2.0 Flash API integration for content generation
